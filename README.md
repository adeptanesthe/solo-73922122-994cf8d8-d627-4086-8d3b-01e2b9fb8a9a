# 高温炉温度采样选点（GP 后验不确定性下降）与超温报警演练

为高温炉温度实验选择 **2 个新增采样时刻** 的网页工具。实验员输入已测时刻/温度、
候选采样时刻、平方指数核长度尺度与观测噪声，系统基于高斯过程（GP）后验协方差，
枚举全部合法候选点对，选择 **全部候选时刻总方差下降最大** 的组合，并展示选点前后
每个候选时刻的方差。

页面同时提供 **超温报警演练**：实验员填入报警温度与一批时刻，系统沿用同一份实测
读数、观测噪声与核参数，从 GP 后验 **独立抽出 3 条炉温轨迹**；演练中可不断插入新时刻
（累计至多 200 个不同时刻），每条轨迹的标记随之更新。

## 数学原理

- 核函数（平方指数）：`k(x, x') = signal_variance · exp(-(x-x')² / (2ℓ²))`
- 观测模型：`y = f(x) + ε`，`ε ~ N(0, σ_n²)`
- 已测数据下的后验协方差：`Σ = K_cc − K_co (K_oo + σ_n²I)⁻¹ K_oc`
- 若在点对 `p = {i, j}` 补充观测：`Σ' = Σ − A (B + σ_n²I)⁻¹ Aᵀ`，
  其中 `A = Σ[:, p]`，`B = Σ[p, p]`
- 目标：最大化总方差下降 `Δ(p) = tr(Σ − Σ') = tr((B + σ_n²I)⁻¹ AᵀA)`，
  枚举所有合法点对取最大（`app/gp.py` 中做了 O(m²) 向量化）

温度观测值只影响后验均值，不影响后验方差，因此选点无需预知未来的测量值；
页面同时展示选点前的后验均值曲线 ±2σ 供参考。

### 演练抽样的数学

设已模拟时刻集合 `S`、新增时刻集合 `N`。先由已测数据得到 `S ∪ N` 上的后验均值
`μ` 与协方差 `Σ`，再以该轨迹在 `S` 上的取值为精确条件，得到 `N` 上的条件分布：

- `μ_{N|S} = μ_N + Σ_NS Σ_SS⁻¹ (y_S − μ_S)`
- `Σ_{N|S} = Σ_NN − Σ_NS Σ_SS⁻¹ Σ_SN`
- 抽样：`y_N = μ_{N|S} + L z`，`L Lᵀ = Σ_{N|S}`，`z ~ N(0, I)`（**联合**抽样）

观测噪声只出现在由已测数据求 `μ, Σ` 的一步（`Σ` 中的 `σ_n²`），`S` 上的已有取值不加噪声。

## 合法性与整批拒绝

合法点对需同时满足：

1. 两个点都**不是已测时刻**（容差：相对 1e-9 / 绝对 1e-12）；
2. 两个点**不重复**；
3. 两点时间间隔 **≥ 最小时间间隔**；
4. 点对协方差矩阵非数值退化（行列式相对阈值 1e-12）。

以下情况**整批拒绝**（HTTP 422，不返回任何部分建议）：

| 情形 | detail.code |
|---|---|
| 输入含 NaN / Inf、参数越界、字段缺失 | `INVALID_INPUT` / `NON_FINITE_INPUT` |
| 观测核矩阵非正定（含数值近奇异，如零噪声下重复已测时刻） | `KERNEL_NOT_PSD` |
| 不存在合法候选点对 | `NO_FEASIBLE_COMBINATION` |

## 网页使用

1. 粘贴或导入 CSV（已测数据每行 `时刻,温度`；候选时刻每行一个）；
2. 填写核长度尺度 ℓ、观测噪声 σₙ（标准差）、核信号方差（温度² 量级）、最小时间间隔；
3. 点击「计算选点」：页面显示选中的两个时刻、总方差前后对比、
   后验均值 ±2σ 曲线、逐候选点方差（选前/选后）明细表；
4. 「载入示例数据」可一键填充一组炉温升温曲线示例。

## 超温报警演练（页面第 4 节）

实验员填写 **报警温度**、**演练时刻**（首批模拟时刻，可含已测时刻）与 **随机种子**，
点「开始演练」后，系统沿用表单中的实测读数、观测噪声与核参数，从高斯过程后验独立抽出
**3 条轨迹**。之后的交互规则：

| 操作 | 行为 |
|---|---|
| 插入新时刻（一次可多个） | 每条轨迹以 **实测读数 + 该轨迹已有取值** 为条件，在新时刻上 **联合** 抽样；已有时刻的取值保持不变 |
| 只改报警温度 | 沿用原轨迹，仅重算每条轨迹的首次超温标记 |
| 加点失败（重复时刻 / 超过 200 个不同时刻 / 数值问题） | 返回 422 并说明原因；页面保留上一次的 3 条轨迹与标记 |
| 改动实测读数、观测噪声或核参数 | 必须重新「开始演练」；页面拦截加点/重标并提示 |

模型语义：

- 观测噪声只作用于 **实测读数**（进入后验均值/协方差），不对轨迹额外加噪声；
- 零噪声时，已测时刻上的模拟值精确等于实测温度；正噪声时允许在已测点附近波动；
- 每条轨迹在已模拟时刻中找 **最早的超温点**（模拟值严格大于报警温度）；未超温则明确
  标注「未超温」；
- 不同轨迹使用同一后验、互相独立的随机流，因而在给定数据下相互独立；
- 演练时刻累计上限 **200 个不同时刻**（按与选点一致的“同一时刻”容差去重）；实测读数
  作为条件数据，不计入该上限。

## API

`POST /api/select`，请求体：

```json
{
  "measured_times": [0, 1, 2, 3, 5, 8, 13],
  "measured_values": [25.3, 196.1, 330.8, 433.5, 578.2, 695.1, 769.9],
  "candidate_times": [0.5, 1.5, 2.5, 10.5, 15.0],
  "length_scale": 2.0,
  "noise_std": 5.0,
  "signal_variance": 100000.0,
  "min_interval": 1.0
}
```

响应：`selected_times`、`selected_indices`、`total_variance_before/after`、
`total_reduction`、`n_pairs_feasible/n_pairs_total`，以及每个候选点的
`eligible / exclusion_reason / variance_before / variance_after / posterior_mean / selected`。
另见交互式文档 `/docs`（FastAPI 自动生成）。规模上限：已测点 ≤ 1000，候选点 ≤ 500。

### 演练接口

三个无状态接口，轨迹状态由页面保存并原样带回；失败一律 422 且不返回部分轨迹。

`POST /api/drill/start`

```json
{
  "measured_times": [0, 1, 2, 3, 5, 8, 13],
  "measured_values": [25.3, 196.1, 330.8, 433.5, 578.2, 695.1, 769.9],
  "length_scale": 2.0, "noise_std": 5.0, "signal_variance": 100000.0,
  "alarm_temperature": 700.0,
  "drill_times": [0.5, 1.5, 2.5],
  "seed": 20261121
}
```

响应：`trajectories`（3 条，每条 `times / values / alarm`，`alarm` 含
`first_time / first_value / index / exceeded`）、`n_distinct_times`、
`max_distinct_times`、`alarm_temperature`、`seed`、`step`。

`POST /api/drill/extend`：同样字段，外加 `trajectories`（原样带回的 3 条）、
`new_times`、`step`；返回追加后的 3 条轨迹与更新后的标记。

`POST /api/drill/alarm`：`{trajectories, alarm_temperature}`，仅重算标记。

演练错误码：`INVALID_INPUT`、`NON_FINITE_INPUT`、`KERNEL_NOT_PSD`、
`DUPLICATE_DRILL_TIME`、`TOO_MANY_DRILL_TIMES`、`DRILL_ERROR`。

## 设计决策与边界

- **新增点数固定为 2**（按需求），核心枚举对所有 C(m, 2) 点对精确评分，非贪心近似。
- 最小时间间隔只约束两个新采样点之间；与已测时刻的间隔通过「已测点排除 + 容差」处理。
- 核矩阵判定严格：零噪声下重复已测时刻直接判非正定；Cholesky 主元低于相对阈值
  （1e-7）也判非正定，不做 jitter 修补——宁可整批拒绝也不给出数值上不可靠的建议。
- 已测时刻允许为空（退化为先验），此时选点仍有效。
- 观测噪声参数 `noise_std` 是标准差（矩阵中以其平方进入）。
- **演练有状态逻辑放在前端**（`app/static/index.html`），后端接口无状态：便于实现
  「只改报警温度沿用原轨迹」「加点失败保留上次轨迹」这两条交互要求，也便于在浏览器里
  核对轨迹。
- **轨迹抽样使用可复现 PRNG**（xoshiro128\*\* + Box-Muller + Cholesky），同一随机种子
  与输入必然得到同一批轨迹，便于复现与排查。
- **联合抽样**：新时刻的条件协方差一次性由 Cholesky 分解并乘以同一组标准正态偏差，
  保留新点之间由核诱导的相关性；不是逐点独立抽样后拼接。
- 「该轨迹已有取值」按精确函数值处理（不含观测噪声）；实测读数带观测噪声进入后验。
  这正是“噪声只作用于实测读数”的实现方式：零噪声时已测点模拟值等于实测温度。
- 条件协方差在数值上只有半正定时（例如极近时刻），回退为特征值下限修正后再
  Cholesky，并在响应的 `numerically_adjusted` 标记；正常数据不触发。
- 「同一时刻」判定沿用选点的相对 1e-9 / 绝对 1e-12 容差；重复时刻拒绝而不是覆盖，
  保证已模拟取值不可变。
